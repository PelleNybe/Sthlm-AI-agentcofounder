# AgentCofounder Starter Repository

An open-source, autonomous AI agent workflow harness designed for the Stockholm AI AgentCofounder Hackathon. This engine takes raw human product ideas and dynamically builds fully tested, functioning web applications.

## Technical Improvements Implemented

1. **Real-time Data Source Integration & Chart Enhancements**: Upgraded the mock UI dashboard to a fully functional React `Dashboard` that attempts to fetch telemetry from an API, gracefully falling back to a realistic synthetic dataset if unavailable. Added dynamic chart config options.
2. **Complete Frontend Error Boundary & Loading State Handling**: Implemented robust React error boundaries (`ErrorBoundary.tsx`) to catch component tree crashes alongside an interactive, animated Skeleton loading state.
3. **Comprehensive End-To-End API Testing**: Integrated Vitest and React Testing Library setup in the `app-template` with mocked Recharts SVGs to run full end-to-end component tests mimicking user journeys.
4. **LocalStorage Persistence for Dashboard Config**: Added a reusable `useLocalStorage` hook, enabling users to persist their graph preferences (line width, color, grid visibility) across page refreshes.
5. **Fix TokenPruner Mock & Properly Integrate AST Compression**: Adapted the Context7 `tokenPruner.ts` logic to properly sanitize and compress system context sent to the Pi Agent using lightweight Regex fallbacks (to support Node22 without full TS compiler overhead), adhering to the Hackathon token efficiency scoring system.

## Visual Improvements Implemented

1. **Modern Tailwind UI with Theme Switching**: Migrated the generic styling to a highly polished Tailwind CSS responsive layout featuring an accessible Light/Dark/System theme switcher.
2. **Refined Chart Aesthetics & Tooltips**: Switched Recharts basic `<LineChart>` to a beautiful `<AreaChart>` utilizing SVG gradients and frosted glass backdrop-blur tooltips.
3. **Layout & Responsive Design Tweaks**: Added a fully responsive shell featuring a sticky navigation header, mobile hamburger menu, and a restrained maximum content width.
4. **Data Metric Cards**: Introduced three upper metric cards highlighting "Total Operations", "Average Load", and "Peak Activity" with trend indicators for superior at-a-glance dashboard observability.
5. **Polished Animations & Transitions**: Implemented CSS keyframes for staggered slide-up fade-in mounting animations, and smooth hover state transitions across the application.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm run precheck
npm ci
npm --prefix app-template ci
```

### 2. Run the full verification test suite
```bash
npm run check
```

### 3. Run the AgentCofounder Harness
```bash
npm run challenge
```

### 4. Interactive Benchmark Dashboard
Review execution telemetry traces and performance metrics from the previous run:
```bash
npm run dashboard
```

## Structure

*   `solution/` - Contains participant-authored extensions, prompts, and code schemas that dictate the AI Agent's capabilities.
*   `app-template/` - The base starting point for generated applications, equipped with Vite, Tailwind 4, Vitest, and the React Dashboard.
*   `src/` - The underlying test execution harness that runs the agent and verifies its output.
*   `artifacts/` - Execution trace logs (`trace.jsonl`) generated by the framework.
